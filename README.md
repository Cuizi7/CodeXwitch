# CodeXwitch

Codex 账号切换器，一个简单的 macOS 菜单栏程序。

自动保存官方 Codex 的文件登录凭据，手动切换账号时退出并重新启动原 App。沿用同一套配置、项目和会话；设置窗口允许删除已保存账号。

目前完成需求与 UI 设计，尚未实现或发布可运行程序。
